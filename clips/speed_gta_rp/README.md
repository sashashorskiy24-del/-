## Как нарезать

Положите видео рядом (например `clips/speed_gta_rp/video.mp4`) и запустите:

```bash
python3 tools/make_clips.py clips/speed_gta_rp clips/speed_gta_rp/video.mp4               # вертикально 9:16
python3 tools/make_clips.py clips/speed_gta_rp clips/speed_gta_rp/video.mp4 --horizontal  # 16:9
```

Готовые клипы — в `clips/speed_gta_rp/out/`. Субтитры вшиты: крупный Montserrat Black, текущее слово подсвечено жёлтым, мат заменён на `***`.
Поменять момент — правьте `start` (в секундах) в `moments.json`.
